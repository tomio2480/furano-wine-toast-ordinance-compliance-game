# 🖥 当時のウェブサイト風の見た目を，今の技術で描いた方法

## 📝 要約

PR #22 で，タイトル・結果・OGP 画像を 1990〜2000 年代のウェブサイト風にした．
見た目は当時に合わせ，実装は今の CSS と Canvas のままとした．
点描のフィルタ，ドット絵の題字，5 秒で止まる動きの作り方と，検査で踏んだ点を残す．

## 🧭 背景

- 利用者の依頼で，色数・解像度・GIF のコマ数を当時に寄せた
- 範囲はタイトル・結果・OGP 画像とし，遊んでいる間の画面は変えていない
- CSP は緩めない．`img-src 'self'` のため，`data:` の画像は使えない

## 🟦 グラデーションは SVG フィルタで点描にする

なめらかなグラデーションに，`index.html` に直接書いた SVG フィルタ `#web-dither` を掛けた．

- 4 × 4 の Bayer 行列を，`feFlood` 16 個と `feTile` で作る．1 マスは 2px とした
- `feComposite` の arithmetic で色を ±0.1 ずらし，`feComponentTransfer` の discrete で丸める
- 丸めの表は「0 .2 .2 .4 .4 .6 .6 .8 .8 1」とし，最も近いウェブセーフカラーへ寄せる
- 端点の色は，ずらしても同じ段に戻る．このため単色の部分は点描にならない
- 最後に元の透明度で切り抜き直し，文字の外へ色が出ないようにする
- フィルタは `::before` の層だけに掛け，文字・縁・焦点枠には掛けない

表 1. 点描の作り方で検討した形と採らなかった理由．

| 形 | 採らなかった理由 |
|---|---|
| CSS の硬い区切りの帯 | 直線の帯になり，ドット絵の点描にならない |
| `conic-gradient` の模様を重ねる | 混ぜ方が 3 段しかない．要素ごとに層を書き分ける必要もある |
| Canvas で描き，`data:` の URL で背景にする | CSP の `img-src` に `data:` を足す必要がある |
| 要素ごとに Canvas を敷く | 大きさの変化とロールオーバーの色を，JavaScript で追う必要がある |

## 🔤 題字は 1 文字ずつ描いて整数倍に拡大する

- 14px の文字を Canvas に描き，不透明度 50% を境に 2 値の形にする
- 形に縁と影を足し，塗りは同じ Bayer 行列で隣り合う色を混ぜる
- 1 ドットの大きさは，CSS の `round(down, calc(84cqw / 幅), 1px)` で整数 px にする．上限は 4px とした
- 16px で描くと，幅 390px の画面では 1 倍に落ち，ドットが見えなかった
- 14px に下げ，縁と影の余白を隣の文字に重ねて，2 倍に収めた
- 題字はロゴのため，画像の文字でよい（1.4.5 の例外）．元の文字は見た目だけ隠して読み上げに使う
- 文字は `Intl.Segmenter` で書記素ごとに分ける．文字列の展開は lint の `no-misused-spread` に当たる

## ⏱ 動きは 5 秒で止め，触れると流し直す

- 波と虹色は CSS のアニメーションとし，`step-end` で 1 コマ 0.1〜0.15 秒に飛ばす
- 繰り返す回数を決め，4.5〜4.8 秒で止める．WCAG 2.2.2 の 5 秒に収め，止めるボタンは置かない
- 画面を出すと `display` が切り替わり，アニメーションは最初から流れる
- 流し直すときは，`animation` を `none` にして描き直させてから戻す
- 終わったアニメーションは `getAnimations()` に出てこない．このため `cancel` と `play` では流し直せない

## 🖼 OGP 画像は縮めて描き，点描で丸めて拡大する

- SVG を 600 × 315 で描き，Bayer 行列の分だけ色をずらしてウェブセーフカラーに丸める
- なめらかにせず 2 倍へ拡大し，2px のドットを見せる
- 処理は Playwright の中の Canvas で行い，画像を扱う道具は増やしていない

## 🧪 検査で踏んだ点

- 点描の検査は，画面を撮って空のページで読む．本体のページは CSP が `data:` の画像を拒む
- 拡大率が整数でない画面（2.625 倍）では，合成のときに隣のドットと色が混ざる
  - 色がウェブセーフカラーだけかの厳密な検査は，整数の倍率の画面でだけ行う
- 色が変わる回数だけでは，なめらかなグラデーションと点描を見分けられない
  - 同じ色の並びが 2 つ前の色へ戻る回数も数える
- 縦のグラデーションは，行でなく列で調べる．行で調べると 1 色しか出ない
- 5 秒以内に止まることは，`getComputedTiming().endTime` で確かめる
  - 止まらない設定に変えて，検査が落ちることも確かめた
- `list-style` を外したリストは，Chromium ではリストのまま読まれる
  - WebKit 向けに置いた `role="list"` は，属性があることを直接確かめる
