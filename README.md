## 🎮 ゲームの概要

- 舞台は冬の富良野で開く室内の懇親会である
- 会場はコンシェルジュ フラノ 1 階の広間をモチーフにする
- ふらのワインとふらのぶどう果汁以外を持つ参加者に雪玉を当てる
- 全員が適合飲料を持つ間は，乾杯ボタンの長押しで得点を伸ばす
- 得点は SNS に共有でき，ログインすると上位 10 件のランキングに登録できる

公開予定の URL は次のとおりである．

```text
https://tomio2480.github.io/furano-wine-toast-ordinance-compliance-game/
```

## ⚠ 注記

- 本ゲームは非公式のファンゲームである
- 富良野市，富良野市ぶどう果樹研究所，コンシェルジュ フラノとは関係がない
- 題材の「富良野市まずはふらのワインで乾杯条例」は実在する
- ただし努力義務を定めた条例であり，罰則はない
- 雪玉で退場させるルールはゲーム上の誇張表現である．飲み物は自由に選んでよい
- 20 歳未満の飲酒は法律で禁止されている．ぶどう果汁でも乾杯できる
